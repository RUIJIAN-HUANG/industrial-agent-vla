# 每日任务发布自动化

> 状态：已在当前 Codex 工作区启用
> 名称：`XH-202607 每日任务发布`
> 计划：2026-07-25 至 2026-09-02，每天 09:00（Asia/Shanghai）

## 自动化会做什么

每天读取：

- 官方需求基线；
- D01-D40 计划和当天公告；
- 项目看板与风险登记册；
- `CONTRIBUTING.md`；
- 当前 Git 状态、最近提交、PR/测试/日志等可得证据。

然后在 Codex 中输出一份中文 A-F 每日任务公告，包含每人唯一主任务、输入、
输出路径、DoD、依赖、优先级、截止时间、昨日偏差和 P0/P1 风险。

## 自动化不会做什么

- 不自动 commit、push、merge 或修改 GitHub Issue；
- 不把口头进度判定为 Done；
- 不自动修改两份官方 PDF、冻结图或角色边界；
- 不因当天日期改变 Gate 的验收阈值；
- 无证据时会标成 `Partial/Blocked/No evidence`。

## A 的每日操作

1. 09:00 查看自动公告；
2. 根据真实人员可用性做最小调整，并把最终版本同步到团队群或 GitHub；
3. 14:00 处理升级项；
4. 18:00 依据 CI/日志作接受、返工或降级决定；
5. 如需改变发布时间、频道或自动创建 Issue，由 A 单独批准后调整自动化。

若 Codex 自动化不可用，使用
[`daily-task-template.md`](daily-task-template.md) 手工发布，不得跳过当日任务
和日终证据记录。
